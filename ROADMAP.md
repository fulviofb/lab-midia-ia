# Roadmap

Este roadmap organiza os próximos passos do `lab-midia-ia` para transformar a curadoria inicial em um laboratório prático e reproduzível.

## Fase 1 — Fundação da curadoria

- [x] Criar repositório local e privado no GitHub pessoal.
- [x] Criar `README.md` inicial.
- [x] Criar `catalog.yml` com repositórios classificados.
- [x] Criar mapa inicial de ferramentas.
- [x] Criar documento de ética, licenças e privacidade.
- [ ] Validar manualmente licenças marcadas como `unknown` ou `NOASSERTION`.
- [ ] Separar o catálogo em arquivos por categoria quando crescer.

## Fase 2 — Workflows práticos prioritários

Testar e documentar, nesta ordem:

1. `browser-use/video-use` — edição de vídeo com agente.
2. `heygen-com/hyperframes` — vídeo a partir de HTML/CSS/animações.
3. Remotion Agent Skills — vídeo programático em React/Remotion.
4. `jamiepine/voicebox` — voz local-first, TTS, clonagem e ditado.
5. `RVC-Boss/GPT-SoVITS` — TTS/clonagem few-shot.

Cada teste deve gerar:

- pré-requisitos;
- comandos de instalação;
- prompt de uso;
- problemas encontrados;
- custo/API necessária;
- resultado esperado;
- veredito: recomendado, promissor, apenas referência ou evitar por enquanto.

## Fase 3 — Guias para pessoas iniciantes

Criar guias em português para perguntas recorrentes:

- “Quero criar vídeo com IA, por onde começo?”
- “Qual diferença entre Remotion, HyperFrames, Higgsfield e Seedance?”
- “Como criar narração com IA de forma ética?”
- “Como fazer thumbnail/capa com IA sem visual genérico?”
- “Como transformar uma ideia em roteiro, cenas e vídeo?”

## Fase 4 — Templates e exemplos

Criar exemplos reproduzíveis:

- vídeo explicativo narrado;
- vídeo UGC/anúncio de produto;
- thumbnail/capa;
- edição de vídeo bruto;
- prompt cinematográfico para Seedance/Higgsfield.

## Fase 5 — Automação do catálogo

Criar scripts para atualizar metadados do GitHub:

- estrelas;
- forks;
- licença;
- data de atualização;
- linguagem principal;
- status do README.

## Critérios de qualidade

Um workflow só deve ser marcado como “recomendado” se tiver:

- licença clara ou política de uso segura;
- instalação reproduzível;
- documentação mínima em português;
- custos e dependências explícitos;
- riscos éticos/privacidade documentados;
- exemplo ou teste real.
