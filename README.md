# Lab Mídia IA

Curadoria prática em português de ferramentas, skills, prompts e workflows para criar **vídeo, voz, imagem, design e edição com IA**.

Este repositório nasceu a partir de uma curadoria de skills para Claude Code + vídeo animado, mas o escopo ficou mais útil como um laboratório completo de produção de mídia com IA.

## Para quem é

- Pessoas que perguntam como criar vídeos, imagens e vozes com IA.
- Criadores de conteúdo, educadores, consultores e equipes de marketing.
- Desenvolvedores que querem automatizar produção de mídia com agentes.
- Quem quer entender diferenças entre Remotion, HyperFrames, Seedance, Higgsfield, OpenCut, TTS, voice cloning e ferramentas de short video.

## O que este repo contém

- `catalog.yml`: catálogo estruturado dos repositórios e ferramentas.
- `docs/`: guias de escolha, instalação, ética, licenças e workflows.
- `workflows/`: fluxos práticos por tipo de tarefa.
- `prompts/`: prompts reutilizáveis para vídeo, imagem, UGC, narração e thumbnails.
- `examples/`: espaço para exemplos reproduzíveis.

## Categorias principais

1. **Vídeo programático** — Remotion, HyperFrames, HTML-to-video, animações por código.
2. **Edição com agentes** — video-use, OpenCut, FFmpeg, cortes, legendas e pós-produção.
3. **Vídeo automático/social** — Shorts, Reels, UGC, anúncios e vídeos de produto.
4. **Vídeo generativo/cinematográfico** — Seedance, Higgsfield, direção cinematográfica e prompts avançados.
5. **Voz/TTS/clonagem** — Voicebox, GPT-SoVITS, Fish Speech, MisoTTS e ferramentas de narração.
6. **Imagem/design/prompts** — GPT Image, Nano Banana, UI/UX skills, thumbnails e capas.

## Filosofia do projeto

Este repo não é apenas sobre “gerar vídeo com IA”. A proposta é organizar um mapa operacional para:

- criar vídeos por código;
- editar vídeos reais;
- gerar narração e voz;
- usar prompts de imagem e vídeo com mais qualidade;
- escolher a ferramenta certa para cada caso;
- orientar pessoas de forma prática e ética.

## Cuidados importantes

- Nem todo repo com estrelas altas é pronto para produção.
- Alguns projetos dependem de APIs pagas, mesmo sendo open-source.
- Repositórios sem licença clara devem ser **linkados**, não copiados.
- Clonagem de voz e geração de imagem/vídeo exigem consentimento, responsabilidade e cuidado com direitos autorais.
