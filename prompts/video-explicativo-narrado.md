# Prompt: vídeo explicativo narrado

```text
Você é diretor de vídeo educacional e motion designer.

Crie um vídeo explicativo sobre:
[TEMA]

Público:
[PÚBLICO]

Duração:
[30s / 60s / 3min]

Formato:
[vertical 9:16 / horizontal 16:9 / quadrado]

Estilo visual:
[clean, tecnológico, institucional, divertido, infantil, premium, etc.]

Entregue:
1. roteiro narrado em português brasileiro;
2. divisão por cenas com duração estimada;
3. descrição visual de cada cena;
4. sugestões de animação;
5. sugestões de imagem/ícones/gráficos;
6. texto das legendas;
7. prompt para thumbnail/capa;
8. checklist final de qualidade.

Regras:
- evite jargão desnecessário;
- comece com um gancho forte;
- cada cena deve ter uma função;
- linguagem clara e humana;
- visual sem cara genérica de IA.
```
