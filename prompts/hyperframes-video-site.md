# Prompt: vídeo de website com HyperFrames

```text
Usando HyperFrames, transforme este website ou página em um vídeo curto:

URL:
[URL]

Objetivo do vídeo:
[mostrar o site / explicar produto / criar teaser / destacar funcionalidades]

Público:
[PÚBLICO]

Duração desejada:
[15s / 30s / 60s]

Formato:
[16:9 / 9:16 / 1:1]

Tom visual:
[profissional, moderno, institucional, educativo, promocional]

Fluxo esperado:
1. Capturar a identidade visual do site: cores, tipografia, screenshots, seções principais.
2. Propor storyboard com cenas e duração.
3. Criar composição HyperFrames em HTML/CSS/GSAP.
4. Rodar `lint`, `validate`, `inspect`.
5. Gerar snapshots para revisão.
6. Renderizar MP4 final após validação.

Restrições:
- não usar assets externos sem registrar fonte;
- não inventar claims comerciais não presentes no site;
- manter texto curto e legível em mobile;
- se for produto comercial, priorizar benefício e clareza.

Entregáveis:
- storyboard resumido;
- composição HyperFrames;
- snapshots;
- `renders/final.mp4`;
- comandos executados e resultado do `ffprobe`.
```
