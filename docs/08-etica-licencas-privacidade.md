# Licenças, ética e privacidade

## Licenças

Regra prática deste repositório:

| Situação | Ação recomendada |
|---|---|
| MIT / Apache-2.0 / licença permissiva clara | Pode testar, referenciar e eventualmente adaptar com atribuição. |
| AGPL-3.0 | Pode testar e estudar, mas cuidado ao reutilizar código em produtos. |
| Sem licença / unknown / NOASSERTION | Linkar e comentar; não copiar conteúdo substancial. |
| README diz uma licença mas GitHub API não detecta | Verificar manualmente antes de adaptar. |

## Voz e clonagem

Não clonar, sintetizar ou simular voz de outra pessoa sem autorização explícita.

Cuidados mínimos:

- registrar consentimento;
- não usar voz clonada para fraude;
- não simular autoridade, família, clientes ou pessoas públicas sem permissão;
- proteger arquivos de voz como dado sensível;
- informar quando uma voz é sintética, quando aplicável.

## Imagem e vídeo generativo

Cuidados mínimos:

- evitar uso indevido de imagem de pessoas reais;
- verificar direitos de marca, personagens e estilos protegidos;
- evitar deepfakes enganosos;
- marcar conteúdo sintético quando necessário;
- documentar modelo/plataforma usada quando o material for comercial.

## Privacidade

Muitas ferramentas open-source ainda dependem de APIs externas. Antes de subir material sensível:

- verifique se o processamento é local ou remoto;
- leia política da API/provedor;
- remova dados pessoais quando possível;
- não suba gravações privadas de terceiros sem autorização.
